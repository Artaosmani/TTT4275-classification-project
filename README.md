# TTT4275 - Classification project

This repository contains code, documentation, and results for the classification project completed as part of the NTNU course TTT4275 – Estimation, Detection, and Classification**.

## Overview

The project focuses on the design, implementation, and evaluation of classifiers for two distinct classification tasks:

- Iris flower classification** using a linear classifier
- Vowel sound classification** using generative models (Gaussian and GMM)

All classifiers were implemented in Python using jypiter notebook and standard scientific libraries. The Iris task is implementetd in Iris.ipyn and the vowels task is implemneted i Vowels.ipyn

## Dependencies

- Python 3.8+
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn
